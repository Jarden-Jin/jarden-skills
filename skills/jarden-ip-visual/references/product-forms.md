# 产品形态与材质

产品形态在第一轮需求确认时决定，随后进入每一条材质与场景提示词。描述看到的视觉证据，不用「高级、精致」代替材质。

## 毛绒

用分区来写：头部、面部、身体、四肢、配件各是什么。

| 材质 | 需要看见的细节 | 常见失真 |
| --- | --- | --- |
| 短毛绒 | 顺毛方向、细小绒尖、柔和凹凸、细刺绣针脚 | 光滑塑料、油亮胶面 |
| 羊羔卷绒 | 大小有轻微差异的毛圈，面部短绒作对比 | 均匀重复的螺旋贴图 |
| 长毛 | 有长度、分束和毛尖层次，脸边有遮挡 | 把五官全部吞没、边缘像烟 |
| 毛毡 | 稍毛躁的纤维、压实面、针毡颗粒 | 表面像陶瓷或橡胶 |
| 布艺配件 | 织纹、折痕、缝边、真实连接点 | 配件漂浮、绳圈长到脸上 |

五官可用刺绣、毛毡贴片或安全眼的视觉语言；保持已选方案。接缝沿合理的分片走，不为了强调工艺在脸中间乱加线。

悬挂款写明绳从哪接、扣件扣在哪里、重力方向；坐姿有压扁处与接触阴影。不同图里的毛长和扣件不能无故变化。

## 手办

先确认用户具体倾向；还没明确时可在材质方向里对比哑光搪胶、哑光树脂和半透明局部。

- 写实体块面、圆角、涂装边界、柔和高光与细微表面颗粒。
- 三视图要正交或接近正交，正、侧、背轮廓吻合。
- 干净的灰白背景、柔和侧光适合展示涂装；世界观场景可以更有叙事，但角色材质不变。
- 不画露出的网格、操控器、建模界面；不声称已完成工业结构或量产可行性。
- 半透明部件的光透过方式要统一，不让整个身体像发光灯。

## 拼图

拼图的本体是二维画面印在纸板拼片上，不能无故变成立体玩偶。

- 概念阶段定完整画面：主角、配角、环境、色块和细节层级。把图案与产品包装区别开。
- 材质阶段展示纸板厚度、哑光或微光表面、真实拼片接缝，不遮挡五官。
- 透明资产可以是完整拼图面板或明确的图案主资产；提前说明本轮的输出，不编造刀版。
- 场景用桌面、手、收纳盘与半拼装状态交代用途和尺度，盒面沿用同一幅图。
- 完整印刷画面和选定拼缝是同一主资产，换场景不能重画成另一版；需要精确保留时生成背景后合成该资产，按 compose/derive 记录，不冒充新生产品图。不同表面方向也不靠改图案或拼块数量凑差异。
- 片数、成品尺寸、纸材和包装规格没有依据时只在正文或HTML说明未定，不凭画面推断，也不在成图里贴待定或尺度提示。

## 其他周边

先问清具体品类，再映射表面、厚度、边缘和使用方式。

- 亚克力：透明切边、印刷层、真实金属环和反射，不把整张平面插画塑造成雕塑。
- 徽章：金属卷边、哑光或光面印刷、固定方式，针扣不能从正面穿出来。
- 文具：纸张、布面或塑料表面，IP 印刷的位置与大小，打开和使用时结构合理。

不要从这些例子推导固定造型；保留用户的原创角色与品类需求。

## 共用验收

同一角色的材质分区、配色、五官、绳扣和标志配件在整套图里一致。

每张图至少有能说明真实物性的光影或纹理；最终场景还要有尺度和接触关系。缩小到手机屏幕仍能认出角色。场景中的小五金、织带和其他连接也按 [物理审查](physics-review.md) 逐件核对，不能只验主体和大投影。
