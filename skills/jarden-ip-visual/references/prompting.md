# 提示词与视觉验收

目标是接近商业产品图与自然随拍的可信度。清楚的纤维、接触阴影、稳定身份和有用途的场景，比堆风格词有效。

## 生成前的角色约定

在 brief.bible 保存简短角色表，不保存长篇无用设定：

- 轮廓：头身比例、耳朵与四肢形状、站坐姿。
- 五官：眼距、眼形、鼻嘴、固定的小情绪。
- 配色：主色、辅色、占比与分区。
- 记忆点：一个能在小图里认出的配件、花纹或结构。
- 产品：材质分区、缝线、扣件或印刷方式。
- 系列：哪些特征共用，哪些特征按角色变化。

带原图约束身份，带第一只定稿约束系列风格。写清每张参考图的角色，不把多张图混成一只。

## 提示词骨架

每项写成可以独立执行的完整提示词，可按工具习惯使用中文或英文：

```text
任务与图位：为[已确认的产品形态]生成[本阶段/这一张的用途]，竖版3:4。
身份参考：图1为角色[名称]的定稿。保留[轮廓、五官、色区、配件]。
系列参考：图2只约束[比例/工艺/光色]，不要复制它的身份或文字。
主体与材质：[角色、数量、相对大小]，[分区材质、纹理、连接结构]。
场景与动作：[使用关系]，位于[从人设推导的场域]，包含[尺度参照]。
受力与连接：[逐件支撑/悬挂/搭靠点]，[软绳织带的松紧下垂]，[自由金属件的自然姿态与可见约束]。
构图：主角占[比例]，位于[位置]；镜头[角度与距离]；默认干净无字，不预留提示条。
光影：光从[方向]来，呈现[柔软或硬边]投影；有[接触点与形变]。
真实感：[自然纤维差异、细小缝线、轻微使用痕迹、合理景深]。
限制：不改五官/配色/配件，不增加角色，不画文字、水印、界面或棋盘格。
```

不是每项都要写镜头焦距；只使用对画面有贡献的描述。概念阶段替换材质与场景段，专注角色设计。

## 三个方向怎么拉开

| 阶段 | 可以变化 | 应保持 |
| --- | --- | --- |
| 概念 | 比例语言、表情与配件设计、轮廓组织 | 原图的关键身份与用户指定元素 |
| 材质 | 毛型分区、表面工艺、配件材质 | 身份、配色、机位、画幅 |
| 关键场景 | 使用地点、光线与构图策略 | 定稿造型、材质与记忆点 |

每项用一句中文 idea 说明和其他项的区别。相同提示词换三个文件名不能交付。

## 生成后逐张看

1. **身份**：和定稿并排看五官、耳朵、色区、配件；多角色逐只点数，不多、不少、不融合。
2. **真实材质**：毛绒有细毛与压痕，面部不油亮；手办有稳定涂装；拼图仍是平面印刷。
3. **物理关系**：逐件看重力、支撑与连接，挂绳两端闭合、松紧可信；自由环扣不能无可见约束地抗倾倒，软织带不是隐藏支架。脚落地、手指结构与抓握合理，投影与光源吻合。所有场景图另外交给 [零上下文物理审查](physics-review.md)，此处作者自检不能代替。
4. **构图**：主体不被边缘裁掉；手机缩略图可认脸；背景支持主体，不抢视觉中心。
5. **图片功能**：每张提供新信息，整套包含所选类型的必要图位；不能全是同机位换色。
6. **文字**：没有模型伪字、别人的 logo 或水印。默认无附加字，尤其不把真实性、尺度或未知规格提示烘焙进图；用户明确需要的品牌、名字、编号才在拼版阶段添加。原始图已有提示字须编辑去掉，关 overlays 不能消除烘焙文字。
7. **透明与清晰度**：真 alpha、毛边干净、孔洞正确；检查分辨率，避免以低清缩略图冒充高清。

检查不通过先说明具体问题，再编辑或重生成这一张；不要把有问题的图登记成定稿。

## 接近参考帖的质量判断

用自己的成图与同类型参考图比较：材质是否同样可信、角色是否同样好认、图序是否同样清楚、场景能否让人代入真实用法。参考帖中来自截图的页面边框、品牌文字和作者造型不进入成图。

AI 图可能无法直接达到目标，保留失败图与修改原因用于当前项目，迭代后重新看。脚本能验证文件和尺寸，不能替代审美判断，也不能保证销量或互动量。
