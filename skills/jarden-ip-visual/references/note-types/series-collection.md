# 同系列合集

适合一组原创角色出道、测款、预热。重点是「属于同一个系列，但每只都有辨识度」。

## 图片顺序

| 图位 | 内容与作用 |
| --- | --- |
| cover | 全家福：四只可用2×2，更多可用3×N或清楚的拼贴。同比例、同背景、同光线 |
| character-1…N | 每只一张：同机位与主体占比，逐只认脸，名字或编号放底部 |
| scene-1 | 至少一个真实用法：挂包通勤、手持、桌面或相应品类的用法 |
| scene-2 | 换一种合理生活场景，延续同样材质与记忆点 |
| extension | 可选延展或角色关系，不能用无意义重复图补数 |

默认干净无字。用户明确要封面字时，没有品牌名可用已确认的系列名，不发明商标；用 compose.py 或 overlays 按已确认内容添加，不附带提示性声明。

## 系列一致性

先确认第一只的比例、五官、工艺，再逐只做其余角色。身份来自各自输入，风格来自系列首只定稿。

全家福可直接用已定稿单只图拼版。拼版记录 method=compose 与 sources，不冒充新生成。

单只图约占画面六到七成，有稳定接触阴影。脸、耳、配件完整，不用四张不同比例的近景凑合集。

## 为什么要有场景

全家福让人挑款，单只图让人记住，场景让人知道大小与用法。

挂件用包、衣服或手作尺度参照；摆件用桌面物件；拼图用手与桌面。人只需要出镜局部，避免面孔抢主角。

人设与场域要有关联。光线可以是窗边侧光或室内漫射，保留自然投影和轻微生活痕迹；干净但不悬浮。

## 标题和正文

标题建议10到18字，在公告式、投票式、情绪共鸣式中选一种，按用户语气改写。

正文建议2到5行：招呼 → 共同人设或灵感 → 实际进度 → 邀请挑款 → 必要署名。

列出全部角色名，帮助读者在评论里认领。没有打样证据就写设计效果图，不能假装已上市。

## Tag 顺序

建议8到10个，最多10个：

1. 创作或品类大词。
2. 物种、题材、灵感。
3. 方法、工艺或 AI 创作。
4. 有关的情绪与梗。
5. 产品形态、用途或人群。

这一类型默认不把品牌放进 tag，品牌可以在图上露出。每个词必须与图文相关，不机械复制热门词。

## 验收

能一眼数清角色；单只图可横向比较；至少一个使用场景；材质一致；tag 顺序正确；文案没有虚构进度。
