# 多个玩偶多场景展示

适合一组角色一起上新、开箱种草或突出陪伴关系。核心是「这一群怎么一起生活」。

## 图片顺序

| 图位 | 内容与作用 |
| --- | --- |
| cover | 全员合照，一字排开、叠放、并肩或排排挂，能数清款数 |
| group | 换一种排列，或已确认的大小款对比，让每只都能认出来 |
| home | 家里或工位怎么摆，家具、书或常用物给尺度 |
| theme | 从系列灵感推导一个主题场景，不是随机换背景 |
| outing | 带出门的用法：挂包、车内或适合品类的旅途 |
| display | 可选的全系列陈列；没有价格和渠道信息就不编 |

多个场景不是把一组透明图机械粘在不同底图上。要有对应的角度、遮挡、变形、光照和投影。

## 群像组织

同系列共用体型和工艺模板，只在有设计依据的配色、花纹、表情和配件上变化。

每张写清出场名单与数量。超过六只可分组，不让角色变得太小或互相融化。

选择群像关系：并肩表达伙伴、叠放表达拥挤可爱、排排挂表达可携带。不是所有排列都适用于所有品类。

第二张提供新的关系或角度，不能只是第一张换颜色。

## 场景逻辑

至少一个主题场景从灵感来源推导。主题如何转成布景、道具和动作，由原创设计决定，不规定具体水果、植物或节日。

常见递进是家里 → 身上 → 路上，用家具、手、包、书或手机给尺度。

每张都有自然或一致的光源、接触阴影。毛绒纤维保留，五金与绳结稳定。全员合照也不能漂浮。

## 标题与正文

标题建议11到20字，默认不用 emoji。可以用共鸣感叹、真实进度或系列名称。

正文按目的选择：设计师讲灵感与角色，品牌讲设计与用法，真实玩家素材才讲开箱。

写清几只、各自名字和关系。用具体生活场景表达陪伴感，结尾邀请挑款；不写虚构的顾客评价与销售成绩。

## Tag 顺序

建议6到10个，最多10个：

1. 已提供的品牌或账号。
2. 品类。
3. 原创与设计。
4. 相关情绪或梗。
5. 用途与人群。
6. 相关节日或活动；图文无关就跳过。

## 验收

封面全员清晰可数；群像与单角色身份一致；家居、主题、出门功能有区别；尺度与投影可信；文案列出角色名与数量。
