# 单个玩偶多维展示

适合单只上新、品牌种草或展示定制能力。每张图解决一个购买前的问题。

## 图片顺序

| 图位 | 回答的问题 | 表现 |
| --- | --- | --- |
| cover | 长什么样、为什么想点开 | 毛绒优先使用场景认脸，手办可用干净产品海报 |
| scale | 多大、怎么拿 | 手持、挂包或带可靠尺度参照 |
| detail | 质感和工艺怎么样 | 面部、刺绣、配件或表面纹理近景 |
| angle | 其他角度是什么样 | 侧背或3/4角，结构与正面对应 |
| scene-1 | 买回去怎么用 | 一个新用法或生活场景 |
| info | 还需要知道什么 | 已确认包装或新细节图；未知信息只进正文/HTML，信息卡须用户明确要图字 |

默认约六张，用户可以选九宫格再补有意义的图。不要把三张相同挂包图当成不同信息。

## 场景配方

毛绒可用包、手机、手作舞台。低饱和背景与主体形成明度或颜色反差；窗边侧光显出纤维和投影。

人只露手或身体局部，主体在画面中部到中下部，约占三分之一到一半。默认干净无字，靠场景讲清用法，不默认给提示条留空间。

整组重复一个已确认的记忆点，比如绳、布花或特定配件，不能每张随机换。

摆件和手办可用灰白棚拍强调涂装与体块，再补有尺寸参照的桌面或手持场景。

拼图改为完整图、桌面尺度、印刷与拼片细节、包装角度、拼装用法和产品信息，仍只围绕一款。

## 材质验收

毛面分区明确，绒毛在接触处被轻微压住；五官与刺绣针脚清楚。

避免塑料高光、完全对称的程序毛、无投影悬浮、手指融合和挂绳断接。

细节图的五官、缝线、配件必须和封面相同。近景最好基于定稿编辑，不重新随机设计。

## 标题与正文

标题可用「类型 | 品名：副题」，控制20字以内。语气跟随品牌或创作者，不硬写文学腔。

正文：一句引入 → 看得见的设计细节 → 已确认的材质与用法 → 状态说明 → 一个互动邀请。

尺寸和价格未知就写待定；图是 AI 效果图不能写「实拍开箱」。

## Tag 顺序

建议3到7个：品牌（已提供才写）→ 产品名 → 题材 → 品类 → 泛可爱或情绪词。

跳过不存在的类别，不为了凑数发明品牌。相关的长尾词优于一串无关热门词。

## 验收

只围绕一个主角；至少一张给尺度、一张看细节、一张换角度；相同记忆点贯穿；图序和文案能独立理解。
