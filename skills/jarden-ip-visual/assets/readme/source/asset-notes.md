# jarden-ip-visual README 封面源文件

本封面使用真实项目产物与 SVG 排版合成，没有为封面另行生成角色或场景。设计坐标为 1200 × 640，发布用图为上一级的 `hero.png`；`hero-layout.svg` 仅作可编辑源文件，不直接作为 GitHub 展示图。

## 图片来源

三张 JPEG 均从 jarden-ip-visual 的新单款端到端项目正式发布图等比缩小到 600 × 800 后导出。未更换角色、修改产品结构或擦除原图内容。

| 源图 | 正式图位 | 封面用途 |
| --- | --- | --- |
| `hero-cover.jpg` | `01-cover.png` | 主视觉、挂包效果 |
| `hero-scale.jpg` | `02-scale.png` | 手掌比例与触感 |
| `hero-scene.jpg` | `05-scene.png` | 桌面使用场景 |

这些是 AI 设计效果图，不是实物摄影。原项目的图片、审查记录与发布文案仍保留在项目工作区，本封面不代替其验收结论。

## 继续编辑

用浏览器打开本目录的 `hero-layout.svg`，确保三个相对图片引用可加载。字体使用 macOS 系统字体栈，编辑后应重新检查中文宽度。

按 1200 × 640 的画布，以 2 倍像素密度导出透明背景 PNG 到 `../hero.png`。透明区域只在圆角外；照片和正文区域均有实色底。不可用未解析图片引用的系统 SVG 转换结果替代成品。

在 900 像素和 360 像素宽度下检查图片识别、主标题、文字遮挡和浅色／深色页面背景。手机上的详细能力标签属于辅助信息，完整说明仍应留在 README 正文与图片的替代文本中。

建议的替代文本：

> jarden-ip-visual：把原创草图做成毛绒、拼图和手办等 IP 周边视觉，逐轮确认后交付图片、文案与 tag；右侧为同一长耳兔项目的 AI 设计效果图。

用户确认封面后，将 `hero.png` 嵌入本 Skill 的 README。这里保留图片来源与可编辑源文件，安装说明和完整能力介绍仍由 README 正文承载。
