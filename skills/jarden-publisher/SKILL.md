# Jarden-publisher

使用 `video-publisher` 的内容包和任务状态模式。`jarden-ip-visual` 的正式发帖包与用户提供的原图、正文都是素材入口。验收在真实创作页完成。

首次运行见 [配置与依赖](README.md#配置与依赖)。本地校验在 macOS 或 Linux 运行。

## 发布门禁

1. 每个平台都默认停在草稿或发布前预览。只有用户在当前对话明确要求把这份稿件发布到指定平台，才进入 [发布交接](references/commands.md#发布交接)。「继续」「可以」「确认」、稿件通过、上架计划和恢复任务都只按各自的工作范围处理。
2. 展示当前稿件、账号、受众和发布设置，绑定该次预览并重新回读。校验通过后把原页面交给用户。**用户亲自在平台点最后的发布按钮**；即使聊天里重复明确要求发布，Agent 也只交接。这个门禁适用于所有发布入口、定时、同步和平台弹窗。
3. 用户告知已提交后，只读 [核对回执](references/commands.md#回查发布结果)。回执不明时保留待核实状态。

## 确认任务

1. 先区分新稿、恢复原稿、回查提交结果。恢复和回查先读原任务，寻找原账号下同一页面、草稿或作品。仅同标题不够。发现不同内容或账号时停在只读检查。
2. 使用用户点名的平台。未指定时选小红书图文。沿用同任务已确认的图片、首图、顺序和文字。手动素材按明确给定的顺序，目录存在多种排序时先确定图序。
3. 沿用用户或上游提供的文案和话题。确需补齐时给简短提案。B 站使用完整正文并按段落排图。海外两站核对 [实际填入的文案](references/content-package.md#海外图文)，沿用确认的语言。
4. 保存内容包。传图前按 [预检与审核](references/preflight.md) 对本次所有目标平台一起检查账号、位置权限、文案、封面和关键选项，整理成一份清单给用户。已确定的选项沿用，需要用户介入的项目集中处理。保留原图字节，经同意的转换或文案调整另作内容版本。

## 准备与核验

1. 使用用户已登录的账号。检查平台、账号、图文模式、目标页面是否空白，并核对有效本地包。一次只由一个执行者操作创作页面。
2. 小红书使用可用的 [上传与填文案入口](references/commands.md#发起传图)。其他平台在第一次写入前登记任务空间、标签、账号与页面。按 [创作页操作](references/creator-pages.md) 续作，只补缺项。海外网页缺少图文模式、素材入口或必需控件时，交付有序原图、文案和手机交接步骤。
3. 从编辑页独立回读图数、图序、文案、话题以及 [各平台封面和选项](references/preflight.md#封面与发布选项)。B 站核对图片与正文段落的交错顺序。原创、商业合作和 AI 声明分别依据素材、用户说明和平台要求。
4. 素材和计划字段全部回读通过且最终控件可用才记 `ready`。保留页面，交付时给出各平台的实际封面、关键选项、草稿恢复状态和仍需确认的项。平台保存且可找到同一草稿后才报告已存稿。
